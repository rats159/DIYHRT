# DIY HRT
A simple app for running your own Horse Race Tests

**When you open the app, there will be a console window. If you get any unexpected bugs, there should hopefully be some info in that window, which you can use to let me know what happened**

## Info
### Maps
- All maps should be black + transparent, 720x540
- All maps need 1 carrot, 1 gate, and at least 1 spawn.

### Rosters
- Rosters are a set of horses
- Every horse needs an image, a name, and a color (for the win screen)
